My decks are not appearing on my other device

Both devices need to be signed in to the same iCloud account. Open Memo's Settings → Sync: it shows whether the account is signed in, whether a sync is running, and the error if the last one failed. Syncing can take a minute or two.

Does the AI import cost anything?

Memo itself does not charge for it, but Anthropic or OpenAI charge your API account for each file you send, depending on the model and the size of the file. This is separate from any Claude or ChatGPT subscription.

How do I import my own cards?

From the deck list, tap Add and choose JSON or CSV. The file formats are described in the project's README.

Do I need to sign in to GitHub on every device?

No. The sign-in is kept in iCloud Keychain, so signing in on one device covers the others, as long as iCloud Keychain is on. Signing out on one device signs out all of them.
